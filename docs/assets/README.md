# أصول التصميم (Design Assets)

اسقط ملفات الصور هنا عشان تتطبّق أوتوماتيك على المشهد الـ 3D بدون أي تعديل في الكود.
كل الصور تفضّل تكون **PNG بخلفية شفافة** (إلا طاولة/بورتال).

## الملفات اللي النظام بيدوّر عليها

| الملف | الوصف | المقاس المقترح |
|-------|-------|---------------|
| `table.png` | خامة سطح الطاولة الـ 3D | 512×512 (مربع، بيتكرر) |
| `portal.png` | تأثير البوابات الأربعة (توهج دائري) | 256×256 |
| `char-0.png` | شخصيتك (المقعد الأمامي) | 256×384 شفاف |
| `char-1.png` | الخصم 1 | 256×384 شفاف |
| `char-2.png` | الخصم 2 | 256×384 شفاف |
| `char-3.png` | الخصم 3 | 256×384 شفاف |

> لو مفيش ملف، النظام بيرسم بديل إجرائي (أشكال متوهجة) تلقائياً — يعني الموقع شغال دايماً.

## الكروت (DOM cards)
كروت اللعب بتاخد شكلها من بيانات الكروت (`js/cards.js`). عشان تطبّق صور تصميمك على الكروت:
1. اسم الصورة زي `card-<id>.png` وانزلها هنا.
2. بلّغني وأنا أربطها بـ `cards.js` (أو أضيف حقل `img` لكل كارت).
